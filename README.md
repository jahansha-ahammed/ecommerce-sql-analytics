# ecommerce-sql-analytics

E-Commerce Sales & Customer Analytics using MySQL

## Project Overview

This project analyzes e-commerce sales and customer data using MySQL.

The project focuses on solving business questions using SQL queries, from basic data filtering to advanced SQL techniques.

## Database Tables

- customers
- products
- orders
- order_items
- payments

## SQL Concepts Used

### Beginner
- SELECT
- WHERE
- ORDER BY
- LIMIT

### Intermediate
- JOIN
- GROUP BY
- HAVING
- Aggregate Functions

### Advanced
- Subqueries
- CTEs
- Window Functions
- Views
- Stored Procedures
